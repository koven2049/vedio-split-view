A. 树状思维导图

经典思维导图风格。中心主题向外发散，每个分支是一个章节，叶节点是关键要点。适合展示层级关系。

技术方案：Markmap（Markdown → 交互式思维导图）或 D3.js 自绘

B. 结构化卡片（Podwise 风格）

章节卡片 + 关键要点 + 引用高亮，类似 Notion/Podwise 的结构化笔记。信息密度高，阅读体验好。可折叠展开。

技术方案：纯 React 组件，无需第三方图表库

C. 混合模式（概览图 + 详情卡片）

顶部是可交互的简化思维导图/概览，点击节点后下方展开该章节的详细卡片。兼顾全局视野和细节深度。

技术方案：顶部用 Markmap 或 ReactFlow，下方用 React 组件
